# 🤖 DocuMind AI — Hackathon 1

Asistente inteligente desarrollado con **Llama 3.2 y RAG (Retrieval-Augmented Generation)** en Google Colab.

## 📌 Descripción

DocuMind AI permite cargar documentos y realizar preguntas sobre su contenido utilizando inteligencia artificial. El sistema recupera fragmentos relevantes para generar respuestas fundamentadas en las fuentes proporcionadas.

## 🛠️ Tecnologías utilizadas

- Python y Google Colab
- Meta Llama 3.2 1B Instruct
- Hugging Face Transformers
- RAG y embeddings
- Gradio para la interfaz interactiva

## 📂 Archivos

- `DocuMind_AI_Hackathon_LIMPIO.ipynb`: código principal del asistente.
- `Documento_Prueba_EventCore.txt`: documento utilizado para demostrar el funcionamiento.

## 🚀 Ejecución

1. Abrir el notebook en Google Colab.
2. Activar el acelerador GPU T4.
3. Configurar el secreto `HF_TOKEN` con un token autorizado para Llama.
4. Ejecutar las celdas en orden.
5. Cargar el documento de prueba e interactuar con el asistente.

## 🎯 Objetivo

Demostrar la implementación de un asistente inteligente utilizando modelos de lenguaje, Prompt Engineering y recuperación aumentada por generación (RAG).

## 📚 Hackathon 1 — Módulo 1

Proyecto desarrollado como aplicación práctica de los fundamentos de LLM, Llama y técnicas de RAG.
